# PCM System

Sistema de **gestão, monitoramento e análise de materiais PCM (Phase Change Materials)** com integração entre **software, banco de dados e hardware embarcado**.

O projeto foi desenvolvido para **organizar, calcular e acompanhar dados experimentais e operacionais** relacionados a materiais de mudança de fase, muito utilizados em **armazenamento térmico, eletrônica e eficiência energética**.

---

# Visão Geral

O **PCM System** é um software que centraliza **informações técnicas, experimentais e operacionais em um único ambiente**.

O sistema permite:

- Cadastro e gerenciamento de materiais  
- Monitoramento de propriedades térmicas  
- Cálculo de parâmetros energéticos  
- Organização de experimentos  
- Integração com sensores e microcontroladores  
- Análise de desempenho térmico  

Ele foi pensado para ser utilizado em **laboratórios, pesquisas, projetos de engenharia térmica e sistemas embarcados**.

---

# Principais Funcionalidades

## Banco de Dados Inteligente

O sistema possui um banco de dados estruturado para armazenar:

- Materiais PCM  
- Propriedades térmicas  
- Resultados de ensaios  
- Informações experimentais  
- Histórico de medições  

Isso permite **organizar e consultar facilmente grandes volumes de dados**.

---

## Cálculos Térmicos

O sistema permite calcular parâmetros importantes como:

- Energia armazenada  
- Calor sensível  
- Calor latente  
- Eficiência térmica  
- Transferência de calor  

Esses cálculos ajudam a **avaliar o desempenho de materiais PCM em diferentes aplicações**.

---

## Monitoramento Experimental

O software pode ser integrado a **sensores e microcontroladores**, permitindo:

- Coleta de temperatura em tempo real  
- Monitoramento de processos térmicos  
- Registro de dados experimentais  
- Automação de medições  

---

## Integração com Hardware

O projeto foi desenvolvido para integração com sistemas embarcados como:

- ESP32  
- Sensores de temperatura  
- Sistemas de aquisição de dados  
- Projetos de robótica e automação  

Isso permite utilizar o software como **plataforma de monitoramento e controle experimental**.
