🧪 TESTE RÁPIDO

Modo Simulação (5 minutos):
  1. Abra a interface
  2. Sensor → Modo: Simulação
  3. Clique "Iniciar"
  4. Veja temperatura aumentar no gráfico ✅

Modo Serial (10 minutos):
  1. Conecte ESP32 via USB
  2. Sensor → Modo: Serial
  3. Selecione COM3 e 115200 baud
  4. Clique "Conectar"
  5. Veja temperatura atualizar ✅

Modo API (15 minutos):
  1. Conecte ESP32 em Wi-Fi
  2. Sensor → Modo: API
  3. Digite IP: 192.168.200.227
  4. Clique "🔍 Testar" (mede latência)
  5. Clique "Conectar"
  6. Veja temperatura atualizar ✅
